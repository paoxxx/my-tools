# Note Pro（原“笔记软件”）开发文档

集成上课板书、申论批改、自媒体笔记发布的 Mac 笔记软件（Electron）。界面参照 Notability。

## 运行
- 开发运行：`npm start`
- 装进应用程序：`npm run install-app`（代码留在本文件夹，改代码后重开软件即生效）
- 笔记保存位置：文稿/笔记软件（每篇一个 json，文件名就是笔记名，冒号换成全角“：”，重名加（2）；自动保存）

## 文件结构
- main.js：主进程，菜单快捷键、笔记读写、导出（PDF 用 printToPDF 矢量，图片用离屏窗口截图）、我的字体
- docx.js：生成 Word 文档（含极简 zip 打包）
- preload.js：给页面用的 api
- src/js/core.js：排版和墨迹的核心（编辑器和导出共用）
- src/js/app.js：编辑器界面和所有工具
- src/js/export.js + export.html：导出分页
- src/vendor：字体（思源黑体、思源宋体、霞鹜文楷，均 OFL 可商用）、图标、perfect-freehand（压感笔迹）

## 关键设计
- 页面：A4 竖版 210×297mm，页边距按 WPS 普通（上下 2.54cm，左右 3.18cm），1mm = 96/25.4 px
- 文字块两种状态：编辑（textarea，可改字号字体）→ 锁定（不可逆，每个字符一块）
- 锁定时把 chars / xs / ws / lines 写进文档，排版永久固定；两端对齐，标点避头避尾，英文单词和数字不拆行
- 行高：行框 1.4×字号；行距 `ls`（倍数，新文字块默认 1.5，可选 1.2～2.5，老文字块没有 ls 按 1.8），行间距离 =（ls − 1.4）×字号；`rowGaps[k]` 是第 k 行下方额外空间（批注带用）
- 排版时每一行不跨页，超出就整行挪到下一页
- 墨迹挂在“锚点”上：按笔迹中心找它所在的行（`r:块id:行号`），存相对坐标。行移动（批注带撑开、拖动文字块），笔迹跟着走
- 字数：所有非空白字符各算 1（标点算，空格、全角空格、换行不算）

图片：⌘V 粘贴截图到屏幕中央，双击选中，Delete 删除，⌘C 复制，裁剪时 Enter 完成

## 交互原则
- 极简：不弹任何确认框和提示，弄错了 ⌘Z；只有出错（如导出失败）才提示
- 文字块左边的锁头标签显示状态：开锁＝编辑中（点击锁定），关锁＝已锁定（拖动调位置，点击出菜单）
- 标记笔两种状态：落在锁定文字上按字块标记（高亮／加粗／下划线／清除），落在空白或未锁定文字上是普通荧光笔
- 颜色：8 个颜色槽（钢笔共用一组，标记笔一组，文字颜色一组），再点已选中的槽用系统调色盘改这个槽；标记笔有浓、中、淡三档强度
- 镭射：悬空只有红点，按下才有尾迹（整条路径分三层渐细渐淡），不写进笔记
- 橡皮擦、导航（弹簧工具）：用快捷键切过去时，按键按着就一直保持，松开按键才回到上一个工具；只点一下快捷键或用鼠标点选，就用完一次（抬笔）自动切回；按住空格临时变导航，松开恢复
- 自动保存：第一次改动后 0.5 秒内落盘，导出、分享前先立即保存
- 字数：只统计整个文字块，显示在文字块右下角，设置里开关
- 专注模式：收起顶栏，留一个可拖动的悬浮按钮，点一下展开
- 页边距：普通、适中、窄（同 WPS），按笔记保存，新笔记默认窄；已锁定文字块保持原排版
- 笔记标题：笔记 年月日 时:分，同一分钟重名加（1）（2）
- 图片：素材存在 文稿/笔记软件/assets，按中心挂在行上；拖动、四角等比缩放、八向裁剪（不破坏原图）、复制一份、剪切、锁定、上下层、删除
- 文字块：编辑态是富文本（contenteditable plaintext-only），runs 记录每段样式；锁定后 pal（样式表）+ cst（每字样式）；字号可直接输入（8 到 160），选中部分改选中的，不选改整块；字体有思源黑体、思源宋体、霞鹜文楷、得意黑；只记住正文样式

- 批注（⌘3）：锁定文字块每一行下方有隐藏分栏（悬停显示绿色虚线），按住往下拖撑开批注空间，下面所有行整体下沉，墨迹、批注、图片跟着各自的行走；在空白处点一下插入批注文字框（默认很小，随输入变宽，回车换行），颜色 8 槽、小中大字号、字体可选；点已有批注可编辑，按住拖动可移动；写空了自动删除；橡皮擦碰到批注就删掉
- 手写字体（均可商用）：清松手写体1（圆润，SIL OFL，繁简都有，GB2312 一级字只缺 35 个生僻字）、龙藏体、志莽行书（Google Fonts，OFL）

- 我的字体：导入的字体复制到 文稿/笔记软件/fonts（fonts.json 记索引），只在本软件里用，不装进系统；支持 ttf/otf/ttc/woff/woff2 和 zip（自动解压找字体，跳过 __MACOSX）；从 name 表读中文字体名；按需用 FontFace 加载；导出窗口同样加载；导入方式：字体菜单“导入字体…”、文件菜单、拖进窗口、访达“打开方式 → 笔记软件”（需重跑安装脚本）
- 批注分栏不画线，只把鼠标变成上下箭头；只有批注工具（⌘3）能拖分栏，其他工具不碰分栏，避免写字时误触
