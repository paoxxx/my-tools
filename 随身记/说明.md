# 随身记 v1.0（2026-11-04 定版）

## 组成
- 手机App：SuiShenJi.xcodeproj（iOS 18+，免费签名，Bundle ID com.laobob.suishenji）
- Mac自动整理：Mac自动整理/organize.py → 安装在 ~/Library/Application Support/SuiShenJi/，由 SuiShenJiOrganizer.app 后台运行（已授权读iCloud）
- 每周自动重装：Mac自动整理/install_reinstall.sh → 每周日凌晨3点无线重装，失败后每天3点重试

## 数据流
手机录音／图片视频 → Obsidian「1.日记和待办/随身记/.收件箱」→ Mac合并进「随身记/年/年-月/日期.md」→ 停止记录20分钟或最早一条满1小时后，Claude Code整理成分类清单（整理版在上，原文在下）

## 功能
- 豆包流式识别2.0（二遍识别、热词读「随身记/词库.md」），点空白处停止
- 横向说话键随音量跳动；操作按钮可直接开录
- 仿微信选图面板：多选序号、原图开关；图片默认压缩2048，视频默认720P
- 点图片／视频那条可补录语音说明；左滑删除（会同步删除电脑上的原文）
- 列表按今天／本月／今年／往年分层；下拉刷新同步状态

## 常用命令
- 改了organize.py后：cp ~/Projects/随身记/Mac自动整理/organize.py ~/Library/Application\ Support/SuiShenJi/
- 手动整理：python3 ~/Library/Application\ Support/SuiShenJi/organize.py --now
- 手动重装：bash ~/Library/Application\ Support/SuiShenJi/reinstall.sh --now
- 日志：~/Library/Logs/随身记整理.log、~/Library/Logs/随身记重装.log
- 注意：不要再运行install.sh（会重建SuiShenJiOrganizer，授权可能失效）
