# 分句录音器 开发文档

## 用途
口播答题示范、自媒体杂谈的真人分句录音：左边提词，右边按句录音，片段自动排到时间线，拖动裁剪调间隙，重叠处自动交叉渐变，导出 M4A（可放进语音备忘录、iPhone）。

## 技术
- Electron（和贴图剪辑器同一路线），纯原生 HTML/JS，无其他依赖
- 录音：getUserMedia（关掉降噪、回声消除、自动增益，保留原声）+ MediaStreamTrackProcessor 直接读麦克风原始数据（按麦克风自己的时钟，避免无线麦与输出设备时钟不同步产生爆点；不支持时退回 AudioWorklet）；麦克风采样率与播放不同时用 OfflineAudioContext 高质量重采样；录音中检测时间戳断档并提示
- 导出 M4A：先混音成 16 位 WAV，再用 Mac 自带的 `/usr/bin/afconvert` 转 AAC 192kbps

## 文件
- `icon.png` 程序图标；`build/` 图标源文件（icon.svg）和生成脚本
- 启动方式：终端里运行 `fenju`（~/.zshrc 里的别名，等于 cd ~/分句录音器 && npm start），方便迭代
- 热更新：app.js、index.html、style.css 改动后页面自动保存并刷新；main.js、preload.js 改动需在终端 Ctrl+C 后重新运行 fenju
- `main.js` 主进程：窗口、菜单（⌘Z 撤销转给页面）、工程读写、导出
- `preload.js` 桥接
- `index.html` / `style.css` / `app.js` 界面与全部逻辑
- `工程/<工程名>/project.json` 句子、片段位置、增益
- `工程/<工程名>/takes/*.wav` 每次录音原始文件（32 位浮点，无损），裁剪是非破坏的，拖边缘能拉回来

## 关键规则
- 按回车分段，一行一段，一段对应一个片段，重录直接覆盖（1.2起不再按句号断）
- 按 R 前自动保留 0.3 秒预录，防止吃掉第一个字
- 自动去头尾静音：10ms 能量窗口，持续 60ms 才算开口，躲开按键声；头留 0.2 秒，尾留 0.35 秒
- 新录的句子接在上一句后面，留“默认间隙”；后面的句子被压住会自动后推
- “后面跟着动”打开时，拖动或右裁剪某句，后面所有句子一起平移；按住 Option 只动这一句
- 每段头尾按设置淡入（默认0.08秒）淡出（默认0.2秒），两段重叠的部分自动做等功率交叉渐变
- 停顿处补环境声：从录音里找最长的安静段，汉宁窗叠加成可循环的底噪，在人声让出的地方补上，避免数字静音造成的突兀感
- 交叉渐变（对照 Logic 的 X-Fade 拖移模式）：两段重叠的整段区域就是交叉区，前一段等功率淡出、后一段等功率淡入，两段都不裁切；重叠区同时画出两段波形（前一段橙色）和两条渐变曲线
- 吸气样本是全局的“样本库”（偏好里 breathSamples，最多80个，每个单独比对，像任意一个就算），所有工程共用
- 标记吸气：选区这一处直接记成手动吸气（一定压低），同时从选区里挑比底噪响8dB以上、在最响帧12dB内的帧记成样本；“不是吸气”记成手动排除。手动标记存在工程 marks 里，后标的优先，可撤销
- 自动识别只看比房间底噪（10%分位）响8dB以上的帧，避免把安静处当成吸气
- 处理吸气两种模式：静音（默认，吸气处去掉，只留房间环境声补齐）/ 压低若干dB；自动识别的区域前后各多包0.04秒
- Shift 单击紫色吸气区：选中整块，拖边缘扩大后按 B 标记；快捷键 B 标记吸气、N 不是吸气
- 部署注意：往 Mac 写文件时每次用新的暂存目录名，写完核对文件大小（同名暂存文件曾被缓存成旧版本）
- 吸气工具条（bar3）贴在时间线上方；Shift 选区后在选区上方弹出浮窗：标记吸气/不是吸气/试听/放大/取消
- 撤回标记（U）：按标记历史一步步退，连同那次记下的样本一起删；样本平均响度高于 -12dB（相对响亮处）不学，自动识别只认 -9dB 以下的帧，防止误伤说话
- 降噪：每段录音最安静的10%帧当噪声谱，1024点STFT、75%重叠做频谱减法（强度控制过减系数和最低增益），结果按强度缓存；环境声补齐也用降噪后的数据
- 动态均衡：以混音里较响的15%为“正常说话音量”，超过它2dB的部分按3:1压（5ms/150ms）；压峰值：5ms前瞻限幅到 -1dB，80ms释放，最后硬切兜底；开了压峰值，统一音量改为每段对齐 -20dB 后主音量 +4dB
- 段落颜色：8色循环（PALETTE），左边稿子序号、时间线片段左上角徽标、片段背景错位平铺的序号水印同色
- 左上角显示工程名（点击可改名）和“已自动保存 时:分:秒”；窗口标题也带工程名；⌘N 新建（同名自动加 (2)），⌘S 立即保存
- 响度：按 ITU-R BS.1770 的 K 加权＋400ms 块门限算 LUFS（单声道）；目标可选 -14 短视频/流媒体、-16 播客、-23 广播；“一键标准响度”=每段拉齐到 -20dB 再迭代调主音量到目标（最多5次，误差<0.2），过响处由压峰值兜住；导出时顺便显示响度
- 导出时记住上次保存的文件夹（userData/settings.json），下次默认
- 选区：Shift+拖动新建；拖选区边缘可左右调整；Shift+点击在原选区上扩展；Z 放大到选区
- 压低吸气：每512点做1024点FFT，算24个对数频带的“频谱形状”；用 Shift 拖选吸气样本取平均形状，相似度≥0.8、响度在样本±区间内且比说话轻的帧判为吸气，连续0.12～1.5秒才算，压低若干dB（20ms渐变），被压低处由环境声补齐；没有样本时用平坦度、低频占比、频谱重心自动识别
- 录完播放头自动回到这一段开头，空格即回放
- 统一音量：每句取较响的一半 20ms 窗口算平均响度拉到 -20dBFS，再整体抬到峰值 -1dB
