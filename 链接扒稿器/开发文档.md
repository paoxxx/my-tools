# 链接扒稿器 开发文档

版本：1.1.4（2026-11-04）

## 做什么
贴抖音、小红书、B站分享链接（可多条），或拖入本地视频，自动下载音频，在 Mac 本地用 Whisper 转写成逐字稿，存进 Obsidian：
Notes/22-博主逐字稿/博主名/视频标题.md

## 结构
- main.js：主进程，任务排队（一次转写一个）、历史记录、设置（保存位置、窗口位置）
- preload.js：给界面的接口
- index.html：界面（粘贴框、任务卡片、打开笔记、复制逐字稿、在访达中显示；切回窗口自动填入剪贴板里的链接）
- backend/extract.py：下载 + 转写 + 整理标点分段 + 写笔记，每步输出一行 JSON
- scripts/install.sh：一键安装（Python 环境、Electron、应用程序图标、语音模型）
- 设置和历史：~/Library/Application Support/链接扒稿器/

## 技术要点
- 下载：B站、小红书先走 yt-dlp；抖音先走分享页解析（yt-dlp 抖音需要登录 Cookie），失败再互相兜底
- 转写：默认 FunASR 的 SenseVoiceSmall（本地免费，模型从 ModelScope 下载，约1GB）；可选豆包“录音文件识别大模型极速版”（/api/v3/auc/bigmodel/recognize/flash，资源 volc.bigasr.auc_turbo，音频转16k单声道mp3后base64上传，热词放 request.corpus.context），失败自动退回 SenseVoice
- 热词库：保存文件夹里的“公考热词库.md”，## 热词 给豆包，## 纠错（错 → 对）两种引擎转完都替换；软件第一次打开时自动生成
- 密钥：App ID 明文、Access Token 用 safeStorage（钥匙串）加密存在 settings.json，通过环境变量传给后端
- 小红书：后台隐藏窗口打开分享页（未登录用 iPhone 身份，登录后用电脑身份），读 window.__INITIAL_STATE__ 里的笔记数据和视频地址；设置里可“登录小红书/抖音”，登录状态存在 persist:video-sites 分区
- 整理：半角标点转全角，数字两边不留空格，约180字一段
- 应用程序里的“链接扒稿器.app”只是启动壳，真正代码在 ~/链接扒稿器，改代码后重开软件即生效

## 版本记录
- 1.1.4：抖音、小红书网页的风控脚本会试探打开 bitbrowser:// 等外部 App 链接，导致 macOS 弹“未设定用来打开 URL”的框。现在 persist:video-sites 分区拒绝所有权限请求（含 openExternal），并拦截非 http(s) 的跳转、新窗口。
- 1.1.3：点窗口任意空白处（按钮、卡片操作区、底栏、设置面板除外）就从剪贴板粘贴链接，只粘链接本身，已有内容时换行追加，重复链接不再加；切回窗口也自动粘贴（10分钟内扒过的同一条不重复填）；中间弹气泡提示“已粘贴抖音链接，共2条”等；窗口开 acceptFirstMouse，未激活时第一下点击也生效。去掉了旧的“只在输入框为空且链接和上次不同时才填”的限制，这是之前时灵时不灵的原因。
- 1.1.2：豆包改用 Bob 已开通的“豆包录音文件识别模型2.0-标准版”（资源 volc.seedasr.auc，接口 /api/v3/auc/bigmodel/submit 提交 base64 音频，再每2秒 /query 轮询，20000001处理中、20000002排队中、20000000完成）；没开通时再试极速版 volc.bigasr.auc_turbo（Bob 账号未开通，且据说1.0极速版已停止新开通）。带热词提交被拒时自动去掉热词重试。
- 1.1.1：设置里加“保存并测试连接”（用3秒提示音调用豆包，返回成功或“没识别到人声”都算连通）；命令行写入的明文 Token 会在启动时自动改成钥匙串加密。注意：豆包录音文件“标准版”只接受音频网址，所以本软件用的是“极速版”（可直接上传音频）。
- 1.1.0：识别换成 SenseVoice（中文字错率明显低于 Whisper），加豆包可选；Obsidian 公考热词库＋纠错表；设置面板（识别方式、密钥、热词库、平台登录）；小红书改走后台网页抓取并修正 xhslink.cn 短链识别；笔记属性加“识别引擎”。依赖更新用 scripts/update.sh。
- 1.0.3：抖音改为网页方式优先，用调试接口读取网页自己加载的 aweme/detail 视频详情。笔记属性扩充为：标题、博主、博主主页、平台、链接（完整地址）、发布日期、时长、点赞、评论、收藏、分享（B站另有播放）、话题、提取日期；正文前加“简介”（与标题相同时省略）。小红书、B站同样补全这些信息。
- 1.0.2：1.0.1 抓到的是抖音分开传的“纯画面”片段（无声音、2.6秒）。改为：后台网页额外读取 RENDER_DATA 里的完整视频信息，并抓声音轨地址（优先下纯音频，体积小）；每个下载结果都先检查“有声音、时长够”才转写，不合格自动换下一种方式；报错只显示简短原因；开启后台自动播放，保证声音轨会被请求。
- 1.0.1：抖音要求“新鲜 Cookie”导致下载失败。改为软件先用隐藏窗口打开抖音网页（独立的浏览器分区），拿到 Cookie 写进 ~/Library/Application Support/链接扒稿器/cookies.txt，同时抓视频直链；下载顺序改为 yt-dlp（带 Cookie）→网页直链→分享页解析。失败卡片标题显示“没扒下来”。
